# Sistema de Gestão de Frota - UFCD 0791 (TP2)

## Instruções de Compilação
A partir do diretório raiz do projeto (`frota/`), execute o comando para compilar todas as classes dos respetivos packages e direcionar os ficheiros binários para a pasta `bin/`:

```bash
javac -d bin src/modelo/*.java src/servico/*.java src/principal/*.java
